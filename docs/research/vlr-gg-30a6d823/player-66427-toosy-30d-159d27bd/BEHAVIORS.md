# Behaviors

- Header links show the same hover darkening as VLR.gg.
- Mobile hamburger toggles a compact navigation drawer.
- Search field accepts text; submit is intentionally local-only in this static clone.
- Overview is the selected profile tab; Match History has hover feedback.
- Time filters switch the selected visual state between 30d, 60d, 90d and All.
- Layout collapses below 1080px; the right summary column moves below the left column.
- At 720px the desktop-only header controls disappear and the compact header remains.
